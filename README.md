# Ribbo

Mac 看片 App · 4K · Dolby Vision · Atmos

## 下载

**[⬇ 下载最新版 Ribbo.dmg](https://github.com/lumina920/ribbo-releases/releases/latest/download/Ribbo.dmg)**

需要 Apple 芯片（M1 及以后）的 Mac，macOS 15 或更新。

## 安装

1. 双击下载的 `Ribbo.dmg`
2. 在打开的窗口里，把 **Ribbo** 拖进 **应用程序**
3. 从「启动台」或「应用程序」打开 Ribbo

**第一次打开如果提示「无法验证开发者」**：打开「系统设置 › 隐私与安全性」，往下拉，在「Ribbo 已被阻止」旁边点「仍要打开」，输入电脑密码。只需要这一次。

## 更新

装好以后不用再来这里：有新版本时 Ribbo 侧边栏会提示，点「立即更新」就行。

（Ribbo 以前叫 Lumina Player，已经装了的会自动更新成 Ribbo，记录和设置都保留。）

历史版本见 [Releases](https://github.com/lumina920/ribbo-releases/releases)。
